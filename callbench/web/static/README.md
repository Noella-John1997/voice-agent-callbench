# `web/static/` — front-end files

Plain HTML, CSS and JavaScript — no build step, no framework, no external CDN, so it loads fast and works offline.

| File | Purpose |
| --- | --- |
| `index.html` | Page layout: "Test suite" and "Call the agent" tabs |
| `base.css` | Shared design tokens (light + dark mode) and components used by all three projects |
| `app.css` | Styles for personas, transcripts and chat bubbles |
| `app.js` | Calls the API and renders tiles, bar charts, transcripts and the live chat |
